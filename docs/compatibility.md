# 适用范围

唯一严格验收基线：Ubuntu 24.04.5、Linux 6.8.0-149-generic、patched NVIDIA 615.71.09、4×RTX 3090（GA102，24 GiB/卡）。这是历史实机验收，整理仓库时没有重新改驱动、重启或跑负载。

其他内核、驱动、GPU、PCIe switch、虚拟机和不同主板均未在本项目验收。上游支持列表不等于本项目实测。升级内核或驱动后必须重新编译并独立验收。保留可启动的原内核及同版本原厂驱动回退路径。

warm reboot 已通过；断电冷启动未测；四卡同时满载未测。GEMM 按单卡串行，不从单卡测试推断四卡满载能力。

本项目为实验性复现资料。安装前备份将修改的配置、确认本机控制台恢复路径；不要在有任务占用 GPU 时替换驱动。Secure Boot、固件、用户态驱动与内核模块必须满足对应上游要求。
